# 유튜브 채널 평균 조회수 로컬 도구

유튜브 채널의 **롱폼(3분 초과) 영상 평균 조회수**를 무료로 조회하는 로컬 전용 웹 도구입니다.
"최근 10개" / "최근 3개월" 기준을 지원하고, 각 영상을 **일반 vs 광고(협찬)** 로 분류해 평균을 비교해줍니다.

- 브라우저에서 도는 로컬 웹앱 (`http://127.0.0.1:8787`)
- **의존성 설치 불필요** — Node.js만 있으면 `npm install` 없이 실행
- 모든 YouTube API 호출은 로컬 서버가 프록시 (키가 브라우저에 노출되지 않음, 외부에서 접근 불가)
- 채널주소 → `UC`(채널ID) / `UU`(업로드 플레이리스트ID) 변환 도구 포함

> 데이터 규칙·설계 상세는 [`AGENTS.md`](./AGENTS.md), 기획 과정은 [`plan.md`](./plan.md) 참조.

## 1. 준비물

- **Node.js 18 이상** (내장 `fetch`를 사용합니다). 확인: `node --version`
- **YouTube Data API v3 키** — 아래 [3번](#3-youtube-data-api-v3-키-발급) 참고

## 2. 로컬로 받아 실행하기 (pull → run)

### 2-1. 저장소 클론
```bash
# HTTPS
git clone https://github.com/aliexpresskorea2023-lgtm/channel-analysis.git
# 또는 SSH
git clone git@github.com:aliexpresskorea2023-lgtm/channel-analysis.git

cd channel-analysis
```
이미 받아둔 저장소를 최신화할 때:
```bash
cd channel-analysis
git pull origin main
```

### 2-2. 서버 실행
```bash
node server.mjs
```
실행되면 터미널에 이렇게 표시됩니다:
```
  유튜브 평균조회수 · 로컬 웹앱 서버 실행 중
  브라우저에서 열기 → http://127.0.0.1:8787
  API 키 상태      → 미설정 (웹 화면에서 입력)
  중지             → Ctrl+C
```

### 2-3. 브라우저에서 열기
`http://127.0.0.1:8787` 에 접속합니다.

**옵션 — 포트를 바꾸고 싶다면**
```bash
PORT=9000 node server.mjs       # → http://127.0.0.1:9000
```

**옵션 — API 키를 서버 환경변수로 주입** (화면 입력 생략 가능)
```bash
YOUTUBE_API_KEY="AIza..." node server.mjs
```

## 3. YouTube Data API v3 키 발급

1. [Google Cloud Console](https://console.cloud.google.com/) 에 접속합니다. (Google 계정 필요)
2. 상단 프로젝트 선택 → **새 프로젝트** 를 만듭니다. (예: `yt-avg-views`)
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** 에서 **"YouTube Data API v3"** 를 검색해 **사용** 을 클릭합니다.
4. **API 및 서비스 → 사용자 인증 정보** 로 이동 → **+ 사용자 인증 정보 만들기 → API 키** 를 선택합니다.
5. 생성된 키(`AIza...`)를 복사해둡니다.
6. **(권장) 키 제한 걸기** — 키를 클릭해:
   - **애플리케이션 제한**: 로컬 서버가 호출하므로 *HTTP referrer 제한은 걸지 않습니다.* (걸면 오히려 실패할 수 있음)
   - **API 제한**: "키 제한" → **YouTube Data API v3** 만 선택. 이렇게 하면 키가 새어도 다른 API 악용을 막습니다.

> 키는 절대 저장소에 커밋하지 마세요. 웹 화면에 입력하거나 서버 환경변수로만 전달합니다.
> (`.gitignore`에 `.env`가 이미 포함되어 있습니다.)

## 4. 사용 방법

1. **API 키** 칸에 발급받은 키를 붙여넣습니다. `이 브라우저에 저장`을 체크하면 다음 접속 시에도 유지됩니다.
2. **채널 주소** 칸에 채널을 입력합니다. 아래 형식 모두 지원:
   - `https://www.youtube.com/@핸들`
   - `@핸들`
   - `UC...` (채널ID)
   - `https://www.youtube.com/channel/UC...`
3. **UC / UU 변환** 버튼 → 채널명, `UC`(채널ID), `UU`(업로드 플레이리스트ID), 플레이리스트 URL을 보여줍니다. 각 값 옆 `복사` 버튼으로 복사 가능.
4. **기준** 선택:
   - `둘 다 (최근 10개 + 최근 3개월)` — 기본값
   - `최근 10개 롱폼만`
   - `최근 3개월 롱폼만`
5. **평균 조회수 분석** 버튼 → 결과가 나옵니다:
   - 카드: **전체 평균 · 일반 평균(n) · 광고 평균(n) · 광고÷일반 배율** (각 숫자 옆 `복사` 버튼 = 쉼표 없는 원본 숫자)
   - **영상별 분류 표**: 게시일 · 조회수 · 분류(광고/일반) · 길이 · 제목 · 광고 판별 근거
6. **CSV 다운로드** 버튼 → 영상별 원본 데이터를 CSV로 저장합니다.

## 5. 터미널(CLI) 버전

여러 채널을 한 번에 돌리거나 자동화할 때는 `cli.mjs`를 사용합니다. (로직은 웹과 동일)
```bash
export YOUTUBE_API_KEY="AIza..."
node cli.mjs @핸들1 UC... --mode=both --csv=out.csv
node cli.mjs @핸들 --mode=10          # 최근 10개만
node cli.mjs @핸들 --mode=3m --json   # 최근 3개월, JSON 출력
node cli.mjs --selftest               # 네트워크 없이 로직 자가검증(13케이스)
```

## 6. 계산 기준 & 주의사항

- **롱폼** = 영상 길이가 **180초(3분) 초과**. 쇼츠는 평균 계산에서 제외됩니다.
- **최근 3개월** = 90일. **최근 10개** = 필터를 통과한 롱폼 중 최신 10개.
- **광고(협찬) 분류는 키워드 휴리스틱**입니다. YouTube API는 "유료광고 여부"를 공식 필드로 제공하지
  않으므로, 제목·설명·태그의 `광고/협찬/유료광고/스폰서/sponsored/#ad` 등 문구로 판별합니다.
  → 100% 정확하지 않을 수 있으니 **영상별 표의 "광고 근거" 열로 직접 눈검증**하세요.
  → 키워드를 추가/수정하려면 `index.html`(웹) 또는 `cli.mjs`(CLI) 상단의 `AD_PATTERNS` 배열을 편집하면 됩니다.

## 7. API 쿼터 (무료 한도)

- 기본 **10,000 유닛 / 일 / 프로젝트**.
- **리셋 시각은 한국 자정이 아니라 태평양 시간 자정**입니다.
  - 여름(PDT): **KST 오후 4시** / 겨울(PST): **KST 오후 5시**
- 이 도구가 쓰는 엔드포인트 비용:
  - `channels.list` = 1유닛, `playlistItems.list` = 1유닛, `videos.list` = 1유닛(50개당)
  - `search.list` = **100유닛** ← 이 도구는 쓰지 않습니다 (여기서 크게 절약)
- 결과적으로 채널 1개당 대략 **3~20유닛** → 하루에 수백~수천 개 채널 조회 가능.
- 더 필요하면: Google에 쿼터 연장 신청, 또는 프로젝트를 여러 개 만들어 키를 분산.

## 8. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `API 키가 없습니다` | 화면에 키를 입력했는지, 또는 서버를 `YOUTUBE_API_KEY`와 함께 실행했는지 확인 |
| `quotaExceeded` | 일일 10,000유닛 소진. 태평양 자정(KST 오후 4~5시)에 리셋 후 재시도 |
| `keyInvalid` / `403` | API 키 오류 또는 **YouTube Data API v3를 "사용" 설정**하지 않음. 콘솔에서 API 활성화 확인 |
| `채널을 찾을 수 없습니다` | 핸들/ID 오타, 또는 비공개·삭제된 채널. 채널 URL을 그대로 붙여넣어 재시도 |
| 화면이 안 열림 | 서버가 실행 중인지, 포트(`8787`)가 다른 앱과 충돌하지 않는지 확인. 필요 시 `PORT=` 변경 |

## 9. 보안 / 범위

- 서버는 `127.0.0.1`(로컬)에만 바인딩되어 **같은 컴퓨터에서만** 접속됩니다.
- 프록시는 `channels·playlistItems·videos·search` 엔드포인트만 허용합니다.
- 개인·로컬 사용 전제로 만들어졌습니다.
